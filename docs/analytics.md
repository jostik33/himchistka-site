# Аналитика: Метрика, цели, коллтрекинг, UTM

## 1. Счётчик Метрики

1. Создайте счётчик на https://metrika.yandex.ru.
2. Установите код на все страницы перед `</head>`.
3. Включите вебвизор и карту скроллинга — пригодятся для анализа.
4. Проверьте, что визиты фиксируются с телефона и компьютера.

Для статического сайта код можно вынести в отдельный `js/metrika.js` и подключать на каждой странице, чтобы не дублировать.

## 2. Цели

Создайте отдельные цели:

| Цель | Тип | Зачем |
|---|---|---|
| Отправка формы | JavaScript-событие | Основная конверсия |
| Клик по телефону | JavaScript-событие | Звонки |
| Клик в WhatsApp/Telegram | JavaScript-событие | Мессенджеры |
| Заявка подтверждена | Цель из CRM/коллтрекинга | Качественная заявка |

Пример события при успешной отправке:

```js
ym(XXXXXX, 'reachGoal', 'form_submit');
```

Где `XXXXXX` — номер счётчика. Вызывайте после реального успеха, а не по клику.

## 3. Коллтрекинг

Если значительная часть заявок — звонки, без коллтрекинга вы не увидите источник.

- Подключите динамический коллтрекинг (например, через сервис, который поддерживает Метрику и Директ).
- Подменяемый номер должен быть на всех страницах.
- Проверьте, что звонки привязываются к рекламной кампании и ключу.
- Настройте передачу статуса «заявка» в Метрику.

## 4. UTM-разметка

Шаблоны:

```
https://example.com/?utm_source=yandex&utm_medium=cpc&utm_campaign=search_divany&utm_content=ad_01&utm_term={keyword}
https://example.com/?utm_source=vk&utm_medium=cpc&utm_campaign=geo_rayon&utm_content=creative_01
https://example.com/?utm_source=avito&utm_medium=organic&utm_campaign=obyavlenie
```

Правила:

- `utm_source` — площадка;
- `utm_medium` — тип трафика (`cpc`, `organic`, `referral`);
- `utm_campaign` — кампания;
- `utm_content` — объявление или креатив;
- `utm_term` — ключ (для Директа подставляется автоматически).

Не меняйте названия кампаний без причины: история в Метрике станет рваной.

## 5. Отчёты

Минимальный набор в Метрике:

- **Источники, сводка** — визиты, отказы, конверсии по каналам.
- **Конверсии** — по кампаниям и ключам.
- **Электронная коммерция** — если появится оплата онлайн.
- **Карта кликов и вебвизор** — где люди бросают форму.

Раз в неделю смотрите:

1. Сколько заявок пришло.
2. Цена заявки по каналам.
3. Сколько заявок стало заказами.
4. Какие запросы дали мусор.

## 6. Формулы

```
CPL = расходы / количество заявок
CPA = расходы / количество заказов
CR сайта = заявки / визиты × 100%
ROMI = (доход − расходы) / расходы × 100%
```

Для химчистки считайте не только первый заказ, но и повторные: клиент, который вернулся через полгода, меняет экономику.

## 7. Что проверить перед запуском рекламы

- [ ] Счётчик стоит на всех страницах.
- [ ] Цели срабатывают на тестовой заявке.
- [ ] Номера в коллтрекинге подменяются.
- [ ] UTM-шаблоны добавлены в кампании.
- [ ] В Метрике видно источник, кампанию и ключ.
- [ ] Настроен отчёт или дашборд, который вы реально будете смотреть.
